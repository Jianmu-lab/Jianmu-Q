# Local literature inputs

Place readable `.tex` or `.txt` reference sources here for discretization. These are runtime retrieval inputs, not manuscript-writing code.

Full third-party papers and their figures are not bundled. The original workflow used sources with these identifiers:

- arXiv-2102.08920v3
- arXiv-2105.02859v5
- arXiv-2308.04481v3
- arXiv-2401.08044v2
- arXiv-2402.00840v3
- arXiv-2506.16829v2
- arXiv-2606.22602v1

An empty library is accepted. Agents must label independently derived designs as proposals and must not attribute missing content to a paper. Populate the library for literature-backed runs.
